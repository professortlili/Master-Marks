<h2>📌 نبذة عن البرنامج</h2>
<div style="width:180px;height:3px;background:#4CAF50;margin:5px 0 15px 0;"></div>

<p>
<strong>ماستر ماركس</strong> هو برنامج مخصص لأساتذة التعليم المتوسط يهدف إلى تسهيل عملية تقييم التلاميذ وإدارة العلامات بطريقة ذكية وسريعة.
</p>

<ul dir="rtl">
<li>إدخال علامات التلاميذ بسهولة</li>
<li>حساب المعدلات تلقائياً</li>
<li>استخراج إحصائيات دقيقة حول مردود التلاميذ</li>
<li>إنشاء ملاحظات تلقائية حسب أداء التلميذ</li>
<li>تصدير البيانات إلى ملفات الرقمنة</li>
</ul>

<br>
